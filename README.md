# Calculadora Web

**Autora:** YASMIN VIANA CORDEIRO

## Sobre o projeto

Este projeto consiste em uma calculadora web desenvolvida utilizando Python e Flask, com interface em HTML, CSS e JavaScript.

A aplicação permite realizar quatro operações matemáticas básicas:

- Adição (Soma)
- Subtração
- Multiplicação
- Divisão

## Tecnologias utilizadas

- Python
- Flask
- HTML5
- CSS3
- JavaScript

## Como executar o projeto

1. Instale o Python.
2. Instale as dependências com o comando:

   `pip install -r requirements.txt`

3. Execute a aplicação:

   `python app.py`

4. Acesse no navegador:

   `http://127.0.0.1:5000`

## Funcionalidades

- Página inicial com menu de navegação.
- Páginas individuais para cada operação.
- Cálculos realizados pela aplicação Flask.
- Tratamento de divisão por zero.
- Interface personalizada com CSS.
